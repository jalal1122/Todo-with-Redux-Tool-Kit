# ✅ Todo List with Redux Toolkit

A simple and responsive Todo List application built using **React**, **Redux Toolkit**, and **TailwindCSS**. Users can add, edit, and delete todos with smooth state management.

## Live Demo : https://mjtodowithredux.vercel.app/

---

## 🚀 Features

* ➕ Add new todos
* 📝 Edit existing todos
* ❌ Delete todos
* ⚙️ State management via Redux Toolkit
* 🎨 Styled using TailwindCSS

## 📦 Installation

1. **Clone the repository:**

   ```bash
   git clone https://github.com/your-username/todo-with-redux-toolkit.git
   cd todo-with-redux-toolkit
   ```

2. **Install dependencies:**

   ```bash
   npm install
   ```

3. **Start the development server:**

   ```bash
   npm run dev
   ```

4. **Open the app:**
   Visit `http://localhost:5173` in your browser.
